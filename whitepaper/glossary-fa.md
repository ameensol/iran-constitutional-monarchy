## Translation Conventions

- **Code stays English**: Solidity keywords, contract names (`Parliament.sol`), function names (`amendParameter()`), and variable names remain in English within code blocks.
- **Diagram labels stay English**: Mermaid state diagram keeps English state names for rendering compatibility.
- **Article references**: Constitutional article references (Art. II.4, Art. III.6, etc.) remain in their original format.
- **Loanwords**: Where a Persian neologism would be awkward or unclear, the established loanword is preferred (بلاکچین, تراکنش, پارامتر, وتو).
- **1906 Constitution vocabulary**: Where applicable, terms from Iran's 1906 مشروطه Constitution are used (انجمن ایالتی for provincial council, مجلس شورای ملی for Majlis).
- **Quotation marks**: Persian guillemets (« ») are used for Persian quotations; standard quotes (" ") appear only in English code blocks.
